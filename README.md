## 安装与使用
### 安装方法
1. 从release页面下载最新版本的安装包
2. 直接运行安装程序，按照提示完成安装
3. 如果杀毒软件报警，可以选择添加信任或使用免管理员权限版本

### 基本使用流程
1. **登录**
   - 输入学号、密码
   - 点击"刷新验证码或重新登陆"获取验证码
   - 输入验证码后点击"登录"
   - 登录成功后会自动获取profileid (如未获取到，需手动填写)

2. **搜索课程**
   - 选择当前学期
   - 输入课程名称
   - 点击"搜索课程名"按钮
   - 搜索结果会显示在表格中

3. **添加待抢课程**
   - 在搜索结果中点击选择要抢的课程
   - 点击"添加到待抢列表"按钮
   - 可添加多门课程到待抢列表
   - 如需移除课程，选中后点击"从待抢列表移除"

4. **开始抢课**
   - 确保已填写正确的profileid
   - 设置抢课间隔秒数（建议1-3秒）
   - 点击"开始"按钮
   - 程序会为待抢列表中的每门课程创建独立线程
   - 抢课结果会实时显示在控制台文本框中

5. **停止抢课**
   - 点击"结束"按钮可随时停止所有抢课线程
   - 程序会在抢课成功后自动停止相应课程的抢课

## 注意事项
1. 请勿频繁刷新验证码，这可能导致账号被临时锁定
2. 请合理设置抢课间隔时间，避免对教务系统造成过大压力
3. 抢课成功或失败的记录会保存在logs目录下，方便后续查看
4. 如遇到错误，可查看控制台输出的具体错误信息
5. 程序会在连续多次出错后自动暂停相应课程的抢课

## 常见问题
### 无法获取profileid
- 原因：当前不是选课时间，教务系统尚未开放选课功能
- 解决方法：等待选课系统开放后再尝试，或手动填写profileid

### 抢课失败
- 原因1：课程已满
- 原因2：与已选课程时间冲突
- 原因3：不满足选课条件
- 解决方法：请仔细阅读控制台显示的错误信息，根据实际情况调整

### 会话已失效
- 原因：登录状态已过期
- 解决方法：程序会自动尝试获取新的会话，无需手动操作
